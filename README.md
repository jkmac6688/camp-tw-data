# camp-tw-data

「露營安心查」App 的資料檔。內容為交通部觀光署「全台露營場資料」（政府資料開放平臺
資料集 132066）經清洗後的結果，依**政府資料開放授權條款第 1 版**使用。

- `camps.json` —— 全台 1,807 家露營場，14 個欄位
- `manifest.json` —— 版本號、筆數、sha256、官方資料日期

資料由「露營安心查」專案的資料管線（`pipeline/sync.py`）每月自動產出。清洗內容包含：
違反法規欄位的分隔符正規化與長描述保留、超出台灣範圍的座標視為缺值、
電話號碼補回被 Excel 吃掉的前導零、營地網站的黏合 URL 切分與死連結剔除、
字元編碼瑕疵修復。

**本 repo 非政府官方發布，實際狀態請以主管機關最新公告為準：**
https://camp.tad.gov.tw/CMZ/legal.jsp
